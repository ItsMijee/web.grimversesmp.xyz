Peraturan Server

Harap patuhi aturan di bawah ini untuk menjaga kenyamanan bersama.

1. No Cheating / Hacks

Dilarang keras menggunakan client ilegal, X-Ray, fly, killaura, atau modifikasi game apa pun yang memberikan keuntungan tidak fair.

2. Saling Menghargai

Dilarang melakukan rasisme, pelecehan (harassment), atau berkata-kata kasar yang berlebihan di global chat.

3. Bebas Beraksi (Anarchy / Grinding)

Karena ini server berfokus grinding dan bebas, griefing base luar dan raiding diperbolehkan kecuali di area spawn aman.
